# CCL report authoring contract

Prepare a concise Coal India management report using only the selected CCL version data. State the reporting period, units, source coverage, missing files, and uncertainty. Never combine daily and monthly totals. Lead with an executive summary, use a small number of decision-useful charts, explain material variances, and finish with risks, actions, and a source register. Do not invent targets or values. Mark the result as a draft for subsidiary audit.
